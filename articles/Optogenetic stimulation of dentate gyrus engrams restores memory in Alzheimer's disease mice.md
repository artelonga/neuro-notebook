Alzheimer's disease (AD) is a prevalent [[grafo/termos/neurodegenerative disorders|neurodegenerative disorder]] characterized by [[grafo/termos/amyloid beta|amyloid-beta]] (Aβ) plaques and [[grafo/termos/tau|tau]] [[grafo/termos/neurofibrillary tangles|neurofibrillary tangles]]. APPswe/PS1dE9 (APP/PS1) mice have been developed as an AD model and are characterized by [[grafo/termos/plaque formation|plaque formation]] at 4-6 months of age. Here, we sought to [[grafo/termos/better understand|better understand]] AD-related [[grafo/termos/cognitive decline|cognitive decline]] by characterizing various types of [[grafo/termos/memory|memory]]. In order to better understand how memory declines with AD, APP/PS1 mice were bred with ArcCreERT2 mice. In this line, neural ensembles activated during memory encoding can be indelibly tagged and directly compared with neural ensembles activated during [[grafo/termos/memory retrieval|memory retrieval]] (i.e., memory traces/engrams). We first administered a battery of tests examining depressive- and anxiety-like behaviors, as well as spatial, social, and cognitive memory to APP/PS1 × ArcCreERT2 × [[grafo/termos/channelrhodopsin|channelrhodopsin]] ([[grafo/termos/channelrhodopsin-2|ChR2]])-enhanced yellow [[grafo/termos/fluorescent protein|fluorescent protein]] (EYFP) mice. [[grafo/termos/dentate gyrus|Dentate gyrus]] (DG) neural ensembles were then optogenetically stimulated in these mice to improve [[grafo/termos/memory impairment|memory impairment]]. AD mice had the most extensive differences in fear memory, as assessed by contextual fear conditioning (CFC), which was accompanied by impaired DG memory traces. Optogenetic stimulation of DG neural ensembles representing a CFC memory increased memory retrieval in the appropriate context in AD mice when compared with control (Ctrl) mice. Moreover, optogenetic stimulation facilitated reactivation of the neural ensembles that were previously activated during memory encoding. These data suggest that activating previously learned DG memory traces can rescue [[grafo/termos/cognitive impairment|cognitive impairments]] and point to DG manipulation as a potential target to treat [[grafo/termos/memory loss|memory loss]] commonly seen in AD.
